# Lantern

Engine-side Rust for hosting Nyx.

- `crates/nyx-sys`: raw bindings to `nyx-capi`, the C ABI of the Nyx prototype interpreter,
  generated by bindgen from `include/nyx/nyx.h`.
- `crates/nyx`: a safe wrapper over them (see its README).
- `examples/frame-loop`: an engine frame loop that registers a `Log` function and an `Entity`
  type, mounts a Nyx application and runs 20 frames, in safe Rust only.

## Building

`nyx-sys` needs the Nyx sources or an installed `nyx-capi`:

- By default it builds `nyx-capi-static` with CMake from a `nyx-scripting-language` checkout
  beside this repository, on its `proto` branch. Set `NYX_SOURCE_DIR` to use another checkout.
- Set `NYX_CAPI_PREFIX` to a prefix made by
  `cmake --install build --component nyx-capi --prefix <dir>` to link that instead.

Building from source needs CMake 3.30 or later and GCC 14 or Clang 19 (set `CC` and `CXX`).
bindgen needs libclang; set `LIBCLANG_PATH` if it can't find it (for example
`/usr/lib/llvm-19/lib`).

```sh
cargo build
cargo test
cargo run -p frame-loop
```
